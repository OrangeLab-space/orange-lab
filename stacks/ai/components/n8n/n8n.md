N8n is a visual workflow automation platform that allows you to connect different apps and services to automate tasks.

```sh
# Enable n8n
pulumi config set n8n:enabled true

# (Required) encryption key for stored credentials
KEY=$(openssl rand -base64 32)
pulumi config set n8n:N8N_ENCRYPTION_KEY "$KEY" --secret

# Optional: use restored Longhorn volume for app (n8n) and database (n8n-db)
pulumi config set n8n:fromVolume n8n
pulumi config set n8n:db/fromVolume n8n-db

pulumi up
```

## Pocket ID Launcher

n8n supports native OIDC SSO on self-hosted Business and Enterprise plans. The
current component does not configure n8n SSO, so this creates an unrestricted
Pocket ID App Dashboard launcher:

```sh
cd stacks/ai
./components/n8n/pocket-n8n.sh
```

Do not apply the `n8n:auth` commands printed by the script; this client is used
only as a Pocket ID launcher.

## Encryption Key

The key is required to decrypt stored credentials and must be generated by you before deployment - without it they are lost when restoring a database backup or restoring the volume into a new stack. The key is stored encrypted in the Pulumi stack config, but also save it in a password manager:

```sh
pulumi config --show-secrets --json | jq -r '.["n8n:N8N_ENCRYPTION_KEY"].value'
```
